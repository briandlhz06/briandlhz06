## Sobre mí

Me enganché con las computadoras de chico y no lo solté. Me apasiona armar sistemas que anden: lo que se ve, lo que responde atrás, la base y el server. Si hay que hacer un escritorio en WinForms, lo hago. Si hay que dejar un Linux en orden, también.

No me cierra ser el que solo pega pantallas. Quiero entender el sistema entero y que siga firme después del deploy.

[Enlace Sur](https://enlacesur.com.ar) es mi shop. Desarrollo para clientes. Ahí aprendí a entregar, no solo a probar en local.
