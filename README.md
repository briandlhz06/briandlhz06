### Trilogía VPS

Tres tools para un VPS que te pasaron y tenés que dejar sano:

[**Hoztage**](https://github.com/briandlhz06/hoztage) - Escanea el server y te dice qué está mal (puertos abiertos, SSH, Docker, bases). Día 1.

[**Hozfix**](https://github.com/briandlhz06/hozfix) - Lee ese reporte y te arma los comandos para arreglarlo. Día 2.

[**Parole**](https://github.com/briandlhz06/parole) - Guarda cómo quedó y te avisa si después se desvía. Día N.
